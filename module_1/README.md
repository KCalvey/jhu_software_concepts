Module 1 Personal Website
Kari Leigh Calvey

This project is a personal portfolio website built using Python and Flask.

Requirements:
- Python 3.10 or higher
- Flask

Installation and Setup:

1. Navigate to the module_1 directory.

2. Create a virtual environment:

python3 -m venv venv

3. Activate the virtual environment:

source venv/bin/activate

4. Install the required dependencies:

pip install -r requirements.txt

5. Start the Flask application:

python run.py

6. Open a browser and navigate to:

http://localhost:8080

Website Pages:
- Home
- Projects
- Resume
- Contact

Project Structure:
- run.py starts the Flask application
- website/__init__.py creates the Flask app
- website/views.py contains the website routes
- website/templates contains the HTML pages
- website/static contains CSS, images, and files

The application runs on port 8080.
